# Hospital Management System Website

A modern, responsive healthcare website built with HTML, CSS, and JavaScript. This website showcases hospital services, doctor profiles, patient reviews, and provides an intuitive interface for users to learn about the healthcare facility.
## Visit
- https://brahmanandahealthcare.netlify.app/
## 🏥 Features

- **Modern UI Design**: Clean and professional interface with blue and purple gradient theme
- **Responsive Layout**: Fully responsive design that works on all devices
- **Key Sections**:
  - Homepage with hero section
  - Doctor profiles and specializations
  - Medical services overview
  - Patient testimonials and reviews
  - Contact information

## 🔧 Customization

### Modifying Colors
- Open `hospital.css`
- Locate the `:root` section at the top
- Modify the color variables to change the theme

### Adding New Content
- Doctor Profiles: Add new doctor cards in the teams section of `index.html`
- Services: Add new service cards in the speciality section
- Reviews: Add new patient reviews in the reviews section
